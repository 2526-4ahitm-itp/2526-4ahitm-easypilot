Deployment

  • Ziel: LeoCloud (Kubernetes) für Backend und Web-Simulator – vorbereitet
  • URL: it220234.cloud.htl-leonding.ac.at
  • Images: GitHub Actions baut sie und legt sie auf ghcr.io ab
  • Ein Host, ein Ingress: / → Web-Simulator, /api → Backend
  • Bleibt im LAN: Python-Relay, weil sein UDP-Broadcast nur im selben Netz ankommt
  • Doku und Präsentation: GitHub Pages

Tests & CI

  • iOS: Unit-Tests (Swift Testing) für Befehls-Format, Telemetrie, Sound Mode, Profile; UI-Smoke-Test der drei Tabs
  • Backend: Quarkus-Tests für GET /api/status
  • Frontend: Lint und Build
  • alle laufen bei jedem Push und Pull Request in GitHub Actions
