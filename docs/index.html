EasyPilot

Drohnenprojekt der 4AHITM, HTL Leonding · Schuljahr 2025/26

EasyPilot ist eine FPV-Drohne mit einem ESP32-C3 als Companion-Computer. Dazu gehört eine iOS-App, die die Drohne im WLAN findet, die Telemetrie anzeigt und Befehle schickt. Außerdem hat sie einen Simulator, mit dem man üben kann, ohne die echte Drohne zu starten.
